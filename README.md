To run this application fillow the following steps :-

1. Clone this project in your device with this URL - https://github.com/Usbasuthkar/Code-Together.git
2. After cloning, open a terminal to that directory
3. Type the command  `npm i` to install all the dependencies
4. After installing, type the command `npm start`.
5. This will start the user interface, open another terminal to the directory
6. In the new terminal, type the command `npm run server:dev` this will start the server
7. open http://localhost:3000 to open the web app or user interface
